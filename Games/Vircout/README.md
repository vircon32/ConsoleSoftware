# Vircout

Vircout is a basic Breakout-style game for the [Vircon32](https://www.vircon32.com) fantasy console. Break all destructible blocks, collect power-ups and clear all 8 levels while keeping the ball in play.

This game was made by Carra with the help of AI.

## Development

Vircout is the first published Vircon32 game to be written in **Lua** and uses compiler [v32lua](https://github.com/wedge1020/v32lua) together with the Vircon32 development tools to build the final ROM.

I created this entire game through **vibe coding** with ChatGPT. All source code, graphics, sound effects and music were fully generated by AI. The levels were initially created by AI too but I later modified or replaced most of them with my own.

## Building

The Vircon32 development tools and v32lua must be installed and available in your system PATH.

On Linux and macOS:

    `make`

On Windows:

    `build_windows.bat`

The resulting ROM will be created as `bin/Vircout.v32`.

## Game assets

All graphics and sound except for the sprites texture have been generated procedurally using `Python 3`. To regenerate those assets before building, use these commands:

    `make regen-graphics`
    `make regen-audio`

Or, on Windows:

    `python tools/make_graphics.py`
    `python tools/make_audio.py`

For these generations you will need 2 Python libraries: `Pillow` for the graphics, and `numpy` for the audio.
